## About

I build **AI-powered products end to end**: from the dataset and the model to the API, the interface and the tests. My focus is applied machine learning and NLP for African contexts, delivered as reliable software that real teams use every day.

I care about **engineering rigour**: typed code, migrations, automated tests, honest model evaluation and clear limits on what the AI is allowed to decide. I also **teach software engineering**, which keeps my work clear, documented and easy for others to build on.

**Currently**

- 🛰️ **Code for Africa AI for Good Fellow** — technical lead on [SaoCheck AI](https://github.com/P-Adjinsala/saocheck-ai), an AI-assisted fact-checking platform built with WenakLabs in Chad.
- 🌍 **Full-Stack Developer & Webmaster** at AfricTivistes CitizenLab Cameroun.
- 🎓 **Software Engineering Lecturer** (databases, web programming) at ISTEM and IUSTY.
